# Data Analytics Projects

A collection of projects I've built while learning Python, data analysis, and introductory machine learning

## Projects

### 💸 [Student Budget Tracker](./student-budget-tracker/)

**Python · NumPy**

A simple command-line program built to practice Python fundamentals with example budget and expense data.

- Displays expenses by category and checks the remaining budget.
- Finds expenses above the average using NumPy.
- Uses functions, conditionals, loops, and a text-based menu.

**Explore:** [Python script](./student-budget-tracker/Student_Budget_Tracker.py)


### 📊 [Student Performance Analyzer](./student-performance-analyzer/)

**Python · NumPy · Pandas · Matplotlib · scikit-learn**

An introductory data analysis and machine learning project using synthetic student-performance data.

- Explores student scores and study hours using NumPy and Pandas.
- Trains a linear regression model to predict exam scores from study hours.
- Evaluates predictions using mean absolute error (MAE) and R², and visualizes the regression.

**Explore:** [Python analysis and model](./student-performance-analyzer/student_analyzer.py) · [Practice notebook](./Student%20Performance%20Analyzer/learning_module.ipynb)


### 🚲 [Bike Sharing Demand Analysis](./bike-sharing-demand-analysis/)

**Python · Pandas · NumPy · Matplotlib · Plotly · Streamlit**

Explores daily bike-sharing demand in 2011–2012 using the [UCI Bike Sharing Dataset](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset).

- Investigates rental patterns over time, seasonal differences, and weather conditions.
- Compares average daily rentals between 2011 and 2012.
- Includes a Streamlit dashboard with year, month, and weather filters, summary metrics, and interactive charts.

**Explore:** [Dashboard source](./bike-sharing-demand-analysis/app.py) · [EDA notebook](./bike-sharing-demand-analysis/data_exploration.ipynb) · [Project README](./bike-sharing-demand-analysis/README.md)
